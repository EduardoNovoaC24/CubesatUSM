# Hardware CubeSat USM

`hardware/` contiene los dos diseños KiCad y las revisiones de montaje, soldadura inferior, mecánica, GPIO26 y Arducam.

- [Shield PD UART](hardware/STM32L476RG_PD_UART_Shield/README.md)
- [Shield de dos capas](hardware/STM32L476RG_Shield_2Layer/README.md)

Abre el archivo `.kicad_pro` de la variante en KiCad. Cada carpeta conserva sus tablas de librerías, huellas, esquemas, pinout y BOM. Para fabricar, revisa la documentación y confirma qué revisión corresponde al montaje físico.
